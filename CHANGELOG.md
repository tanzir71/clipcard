# Changelog

## Unreleased

## v0.4.0 - 2026-11-21

- Make cards in 30 languages, with right-to-left layouts for Arabic, Urdu and Persian.
- Switch languages in the extension, web app and landing page. Some interface text still uses English.
- Add your own mark and set defaults for the card style, QR code, texture and draft history.

## v0.3.0 - 2026-11-20

- Clip quotes, images and sections with the extension and turn them into a grid with a QR code for each source.
- Use the bookmark on several pages to make a single Excerpts card in the web app.
- Name a draft, close it and return to the same clips and layout later.
- Export drafts to a ZIP, import a backup and choose how long drafts stay in this browser.

## v0.2.1 - 2026-11-20

- Site access is opt-in. The extension uses temporary access to the current tab when you invoke a toolbar, menu or shortcut action.

## v0.2.0 - 2026-11-20

- Install the Clipcard beta in Chrome, Edge or Brave.
- Right-click a link, page or quote to copy a card with a QR code back to the source.
- Edit the headline, style and format in a popup at the top right, then copy or share the result.
- Make Caps and Duotone cards and export 16:9 and 1.91:1 formats.

## v0.1.0 - 2026-11-20

- Paste a link, copied article or photo to make a card in the web app or on the home page.
- Copy or save a PNG in five styles. Sourced cards include a QR code back to the original.
- Use the Clipcard bookmark to make a card from the page you’re reading.
- Install Clipcard on your phone and reopen recent cards offline. On Android, share links directly to Clipcard.

## v0.0.0 - 2026-11-20

- Meet Clipcard and see which features are coming.
- Explore sample cards in six styles, including examples in Bangla, Hindi and Urdu.
- Follow the project on GitHub or share the landing page from your phone.
