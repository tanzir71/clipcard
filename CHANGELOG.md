# Changelog

## Unreleased

## v1.0.1 - 2026-11-21

- Use Noto Sans Bengali for Bangla text and card exports.
- Fix the Arabic and Urdu hero layout and preserve language choices between the landing page and web app.

## v1.0.0 - 2026-11-21

- Install the complete Clipcard extension through Chromium Developer mode.
- Try the Firefox temporary add-on for sourced cards, clippings, and video moment cards.
- Share an MP4 into the web app on supported phones and finish it from a local video draft, even offline.
- Find the Chromium and Firefox downloads together on the landing page.

## v0.7.0 - 2026-11-21

- Collect headlines by dragging across a page, gathering open tabs, or pasting a list of links.
- Make a Roundup with four stories per page, save a numbered Carousel ZIP, or turn the same links into a Digest video.
- Record a tab in the web app with the browser’s permission, then finish the video from your local draft.

## v0.6.0 - 2026-11-21

- Join recorded clips, excerpts and pictures into a video in the extension or web app. Reorder the scenes, trim clips and edit captions on the timeline.
- Use your own GIFs for reactions and export with a Sources card that links back to the originals.
- Save photos, GIFs and clips to your Library. Search, tag or favorite them, and include them in a draft backup.
- Browse GIPHY and KLIPY with your provider key. The search results link to their original pages.

## v0.5.0 - 2026-11-21

- Select a range on a video and make a moment card with a QR that opens the source at the selected time.
- Record up to 60 seconds in the extension by sharing the tab that’s playing the video. Keep clips in the current draft and return to them later.
- Export a portrait video with the original tab audio, available captions and a Sources card.
- Use the Clipcard bookmark to make a timestamped moment card in the web app.

## v0.4.0 - 2026-11-21

- Make cards in 30 languages, with right-to-left layouts for Arabic, Urdu and Persian.
- Switch languages in the extension, web app and landing page. Some interface text still uses English.
- Add your own mark and set defaults for the card style, QR code, texture and draft history.

## v0.3.0 - 2026-11-20

- Clip quotes, images and sections with the extension and turn them into a grid with a QR code for each source.
- Use the bookmark on several pages to make a single Excerpts card in the web app.
- Name a draft, close it and return to the same clips and layout later.
- Export drafts to a ZIP, import a backup and choose how long drafts stay in this browser.

## v0.2.1 - 2026-11-20

- Site access is opt-in. The extension uses temporary access to the current tab when you invoke a toolbar, menu or shortcut action.

## v0.2.0 - 2026-11-20

- Install the Clipcard beta in Chrome, Edge or Brave.
- Right-click a link, page or quote to copy a card with a QR code back to the source.
- Edit the headline, style and format in a popup at the top right, then copy or share the result.
- Make Caps and Duotone cards and export 16:9 and 1.91:1 formats.

## v0.1.0 - 2026-11-20

- Paste a link, copied article or photo to make a card in the web app or on the home page.
- Copy or save a PNG in five styles. Sourced cards include a QR code back to the original.
- Use the Clipcard bookmark to make a card from the page you’re reading.
- Install Clipcard on your phone and reopen recent cards offline. On Android, share links directly to Clipcard.

## v0.0.0 - 2026-11-20

- Meet Clipcard and see which features are coming.
- Explore sample cards in six styles, including examples in Bangla, Hindi and Urdu.
- Follow the project on GitHub or share the landing page from your phone.
