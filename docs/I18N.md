# I18N — Clipcard

Built for Bangladesh and similar markets where news travels as clipcards.

## 1. Languages

Prioritized for markets where misinformation spreads fastest through shared images (Facebook, WhatsApp, Telegram) and where fact‑checking and platform moderation are weakest in the local language.

**Two layers ship on different schedules:**
- **Card support** (script detection, fonts, numerals, direction): every language below works at launch. It costs only fonts and tests.
- **UI translation** (menus, sheet, settings, store listing, landing page): ships in waves, because each language needs a native reviewer.

Two independent settings:
- **Interface language**: from the browser locale by default; changeable in settings and on the welcome page. Untranslated locales fall back to English.
- **Card language**: detected per article (`docs/ARCHITECTURE.md` §5). It drives fonts, numerals and direction on the card. Users can override it per card from the quick sheet (via a tooltip menu on the source tag, so no visible label).

## 3. Numerals & dates

- `Numerals: Native | 0–9` setting. Native defaults: `bn` → ০১২৩, `ne` → ०१२३, `ar` → ٠١٢٣, `ur` → ۰۱۲۳ (Eastern), `hi` → 0–9.
- Use `Intl.NumberFormat`/`Intl.DateTimeFormat` with the `-u-nu-` extension (e.g. `bn-BD-u-nu-beng`). Dates are not printed on cards (minimal text); they appear only in history.

## 4. RTL

- Card: mirrored layout (`docs/DESIGN.md` §4.4). The QR stays a QR (never mirrored); the photo is not flipped.
- UI: `dir="rtl"` on the quick sheet, toast, welcome and settings pages when the interface language is `ur`, `ar` or `fa`. Use logical CSS properties (`margin-inline-start`, `inset-inline-end`). The toast anchors bottom‑left.
- Wrap URLs, domains and `@handles` in `<bdi dir="ltr">`.

## 5. UI strings

- Source of truth: `packages/i18n/locales/<lang>.json` (flat keys). `en` and `bn` are seeded. Generate the other wave‑1 locales from `en` and mark them `"_status": "needs-review"`; they must be translated and signed off by native speakers before release. Ideally recruit local fact‑checking organizations as reviewers; they are also the best early users.
- The build generates `apps/extension/public/_locales/<lang>/messages.json` for `chrome.i18n` (manifest name and description, context menu titles) from the same JSON.
- Keep strings short: the UI has fewer than 50 visible strings by design. No sentences on cards.
